# Top Doc Compressor Skill

## 개요

설계 초기에는 architecture.md처럼 하나의 상위 문서에 모든 내용을 담습니다.
하지만 be_design.md, db_design.md, fe_design.md가 생기면 상위 문서와의
중복이 발생하고, 어느 쪽이 정본인지 불명확해집니다.

이 스킬은 상위 문서를 "조감도(overview)" 역할로 압축하고,
상세 내용은 하위 문서를 정본으로 확립합니다.

## 이 스킬을 사용하는 시점

- 상위 문서(architecture.md)와 하위 문서(be/fe/db)가 동일 내용을 중복 기술할 때
- 상위 문서가 너무 길어져 "어디가 정본인가" 혼란이 생길 때
- 하위 문서가 완성됐는데 상위 문서가 아직 압축되지 않았을 때

---

## 1. 중복 분석 매트릭스

각 섹션을 아래 4가지로 분류합니다:

| 분류 | 정의 | 처리 방법 |
|------|------|----------|
| **A. 상위 전용** | 하위 문서에 없는 전체 조감 내용 | 유지 |
| **B. 완전 중복** | 하위 문서에 동일 내용이 그대로 있음 | 상위에서 삭제 → 링크로 대체 |
| **C. 요약 유지** | 하위에 상세가 있고, 상위엔 3~5줄 요약만 필요 | 상위 압축 후 "→ 상세: [문서]" 링크 추가 |
| **D. 상위 고유 정보** | 하위 문서 어디에도 없는 결정사항 | 가장 적합한 하위 문서로 이전 후 삭제 |

---

## 2. 실행 절차

### STEP 1: 상위 문서 섹션 목록 추출

대상 상위 문서의 전체 섹션(H2, H3)을 목록화합니다.

### STEP 2: 섹션별 하위 문서 비교

```text
for each 섹션 in 상위 문서:
  1. be_design.md에 동일 또는 유사 섹션이 있는가?
  2. fe_design.md에 동일 또는 유사 섹션이 있는가?
  3. db_design.md에 동일 또는 유사 섹션이 있는가?
  -> 분류: A / B / C / D 중 하나 선택
```

### STEP 3: 중복 분석 테이블 출력

```markdown
| 섹션 | 내용 요약 | 분류 | 하위 문서 위치 | 처리 방향 |
|------|-----------|------|----------------|----------|
| §2 아키텍처 원칙 | 7개 원칙 목록 | B. 완전 중복 | be_design.md §2 | 삭제 → 링크 |
| §15 환경변수 목록 | .env.example 키 | D. 상위 고유 | be_plan.md 미존재 | be_plan.md로 이전 |
```

### STEP 4: 사용자 확인 후 압축 실행

**B (완전 중복) 처리 예시**:
```markdown
# 압축 전
## 7. 상세한 동기화 흐름
[길고 상세한 내용 500줄]

# 압축 후
## 7. 동기화 아키텍처 (요약)
Local-First 원칙 기반. 로그인 후 bootstrap → push/pull 흐름.
충돌 시 version 기반 409 + serverSnapshot 교체 정책.
→ 상세: [docs/04. be/be_design.md §7-9]
```

### STEP 5: 압축 후 검증

```text
□ 압축된 상위 문서 라인 수가 원래의 30~40% 수준인가
□ 모든 삭제된 섹션에 하위 문서 링크가 있는가
□ 하위 문서로 이전된 D 항목이 정상 위치에 있는가
□ 상위 문서를 읽으면 전체 시스템 구조를 파악할 수 있는가
□ 하위 문서 없이 상위 문서만으로 구현 진행이 불가능한가 (-> 역할 분리 완성)
```

---

## 3. 압축 후 상위 문서 권장 구조

```markdown
# [프로젝트명] — 시스템 아키텍처 (architecture)

## 1. 문서 목적 + 빠른 탐색 (→ 각 파트 정본 링크)
## 2. 아키텍처 목표와 핵심 원칙 (7개 원칙, 한 절)
## 3. 기술 스택 전체 요약 표 (FE + BE + DB + Infra)
## 4. 시스템 컨텍스트 다이어그램 (mermaid 1개)
## 5. 컴포넌트 아키텍처 요약 (모듈 mermaid + 3줄 설명)
## 6. 핵심 정책 요약 (각 5줄 이하: 동기화, 충돌, 세션, 보안)
## 7. 역할별 정본 문서 + 환경변수 참조
```

**트리거**: `$sk-top-doc-compressor`, `/sk-compress-top-doc [파일명]`, 또는 `"상위 문서 압축해줘"`
