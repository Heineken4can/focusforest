Focus Forest 화면정의서

`screen_html_rv8.md` 기준으로 상태, 접근성, 간격 토큰 정리를 반영한 퍼블리싱 인덱스입니다. 대시보드, 집중 모드, 계정/설정 3개 그룹을 동일한 토큰 체계와 Loading/A11y 규칙으로 검토할 수 있게 구성했습니다.

퍼블리싱 기준

`design_system.md v1.6` 준수 항목

  • 공식 토큰 네이밍 `--toss-*` 사용
  • `toss-blue`는 CTA 배경과 인디케이터에만 사용
  • Disabled, Loading, Error, Hover 상태를 화면에 명시
  • 아이콘 버튼 `aria-label`, 타이머 `aria-live`, 스위치 `role="switch"` 반영
  • 알림 버튼 `aria-label`은 `알림`으로 통일
  • 로컬 모드 진입 버튼은 안내 문구와 Loading 예시를 함께 제공
  • 자동 취소 토스트와 카운트다운은 live region으로 안내
  • 비동기 Loading 버튼은 스피너와 함께 `disabled`로 고정
  • 브레이크포인트는 640px / 1024px 기준으로 정렬
