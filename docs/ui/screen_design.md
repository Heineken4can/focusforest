# Focus Forest - 화면 설계서 (Screen Mockups)

`PRD_FocusForest.md` (v1.5) 명세에 기반하여 기획된 핵심 UI 화면들의 시각적 레퍼런스 및 화면 설계 명세입니다.
본 스펙은 `docs/ui/design_master.html`에 정의된 **토스 증권(Toss Invest) 스타일의 다크 모드 기반 디자인 시스템**을 절대 기준으로 따릅니다.

---

## 1. 프론트엔드 작업 시 유의사항
- **단일 진실 원천(SSOT)**: 모든 화면 레이아웃과 룩앤필(Look-and-Feel)은 `docs/ui/design_master.html`의 Tailwind CSS 클래스와 DOM 구조를 기준으로 파생시켜야 합니다.
- **NFR-1 (부드러운 전환)**: 대시보드에서 `[집중 시작]` 진입 시 별도의 페이지 전환 느낌을 최소화하고 `transition-all` 효과를 통한 부드러운 레이어 Dim 연출을 권장합니다.

---

## 3. 화면 상세 정의 (마스터 HTML 기준)

### SCR-02, SCR-03: 대시보드 (기본/과제 선택)
- **참조**: `docs/ui/design_master.html`
- **상세**: `design_master.html`에 구현된 기본 레이아웃. 좌측에 네비게이션, 중앙에 '현재 집중할 과제' 히어로 위젯, 아래에 '오늘의 할 일' 목록 배치. 선을 최소화하고 넉넉한 여백과 명도 차이를 통해 리스트를 구분합니다.

### SCR-04: 집중 모드 (타이머)
- **참조**: `docs/ui/timer_master.html` (예정)
- **상세**: `design_master.html`에서 주변 UI(네비게이션, 할일 목록 등)를 어둡게 처리(dimmed layer)하고, 중앙에 `--color-primary` 블루 컬러의 거대한 프로그레스 바와 숫자를 띠워 다른 요소로 시선이 분산되지 않도록 통제합니다.

### SCR-01, SCR-05 ~ SCR-10: 모달 및 상태 뷰
- **토스 스타일 다이얼로그**: 박스 반경(`rounded-2xl`)이 크고, 여백이 넉넉한 다크 그레이(`bg-[#181B23]`) 배경의 모달을 화면 정중앙이나 하단 노출(모바일 Bottom Sheet 형태)로 띄워 인터랙션 합니다.
