Focus Forest 화면정의서 퍼블리싱

`screen_design.md`의 10개 필수 화면을 기준으로 `reference_design_master.html`과 `reference_design_timer.html`의 구조를 재사용해 실제 핸드오프 가능한 시각 산출물로 정리했습니다. `design_system.md`의 CTA 대비, 토큰 사용 범위, 반응형, 모달 정책을 반영했습니다.

퍼블리싱 기준

  • `toss-blue`는 일반 텍스트 색으로 쓰지 않고 CTA 배경, 인디케이터, 포커스 용도로만 사용
  • 타이머 숫자는 최상위 계층, 일반 본문은 `toss-textMain`/`toss-textSub`만 사용
  • Selected, Disabled, Error, Warning, Success 상태를 화면에 직접 노출
  • 모바일은 Bottom Nav / Bottom Sheet, 데스크톱은 센터 모달과 다열 레이아웃 우선
