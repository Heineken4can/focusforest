# QA 계획서 - Auth (Login, Logout)

## 기본 정보
| 항목 | 내용 |
|------|------|
| 대상 기능 | Authentication (로그인, 로그아웃) |
| 테스트 도구 | Playwright (E2E) |
| 작성자 | Antigravity (QA) |
| 작성일 | 2026-03-13 |

## 테스트 목적
- 로그인 및 로그아웃 기능의 정상 동작 확인
- 예외 상황(잘못된 정보 등)에 대한 UI 피드백 검증
- 로그아웃 후 보호된 경로 접근 차단 검증

## 테스트 시나리오 (TC)

### TC-AUTH-001: 로그인 성공
- **단계**:
  1. `/auth` 페이지 접속
  2. 유효한 이메일/비밀번호 입력
  3. 로그인 버튼 클릭
- **기대 결과**: `/dashboard`로 이동하며 인증 상태가 유지됨.

### TC-AUTH-002: 로그인 실패 (잘못된 비밀번호)
- **단계**:
  1. `/auth` 페이지 접속
  2. 올바른 이메일 + 틀린 비밀번호 입력
  3. 로그인 버튼 클릭
- **기대 결과**: 에러 메시지("이메일 또는 비밀번호를 다시 확인해 주세요.")가 노출되고 페이지가 유지됨.

### TC-AUTH-003: 로그아웃
- **단계**:
  1. 로그인 완료 상태에서 `/settings` 페이지 접속
  2. 로그아웃 버튼 클릭
- **기대 결과**: `/auth` 페이지로 리다이렉트되며 세션이 종료됨.

### TC-AUTH-004: 비인증 사용자 보호 경로 접근 불가
- **단계**:
  1. 로그아웃 상태에서 `/dashboard` 직접 접근 시도
- **기대 결과**: `/auth` 페이지로 리다이렉트됨.

## 환경 설정 및 실행 계획
1. `frontend` 디렉토리에 Playwright 설치 (`npm init playwright@latest`)
2. `e2e/auth.spec.ts` 테스트 코드 작성
3. 백엔드 및 프론트엔드 서버 실행 상태에서 테스트 수행
