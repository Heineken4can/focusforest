## 1. 문서 역할

### 1.1 목적
- V1 범위의 필수 화면을 빠르게 합의한다.
- 각 화면의 구조, 주요 섹션, 핵심 행동을 텍스트 기준으로 정리한다.
- 이후 `ui_reference_design_*.html` 시안과 `design_system.md`를 연결하는 기준 문서로 사용한다.

### 1.2 산출물 관계

## 2. V1 설계 원칙

### 2.1 제품 경험 원칙
- 사용자는 한 번에 하나의 핵심 과제에만 집중한다.
- 대시보드는 준비 상태, 집중 모드는 몰입 상태, 인증/설정은 보조 관리 상태로 구분한다.
- 집중 모드에서는 편집보다 수행이 우선이며, 방해 요소는 최소화한다.
- 로컬 모드와 로그인 모드 모두 동일한 핵심 집중 루프를 경험할 수 있어야 한다.

### 2.2 화면 구조 원칙
- 대시보드: 할 일 목록, 핵심 과제, 오늘의 통계가 중심이다.
- 집중 화면: 타이머, 현재 과제, 세션 제어가 중심이다.
- 인증/설정 화면: 폼, 프로필, 동기화/테마/타임존 설정이 중심이다.

### 2.3 반응형 원칙
- 모바일: 단일 컬럼, 하단 메뉴 중심
- 태블릿: 단일 컬럼 유지, 좌측 메뉴 축약 가능
- 데스크톱: 좌측 메뉴 + 메인 콘텐츠 + 선택적 보조 영역

### 2.4 상태 원칙
- Empty, Loading, Disabled, Error, Success 상태를 모든 핵심 화면에 정의한다.
- 집중 세션의 상태 변화는 `진행 -> 일시정지 -> 재개/포기 -> 완료 -> 휴식` 흐름으로 이해한다.
- 보상은 25분 집중 세션 완료 시점에 확정되며, 휴식 Skip 여부와 무관하게 유지된다.

## 4. 화면 그룹 설계

### 4.1 대시보드 그룹
대시보드 그룹은 사용자가 오늘 해야 할 일과 현재 집중할 과제를 정리하는 공간이다. 목록 관리, 핵심 과제 선택, 오늘의 성과 확인이 한 흐름으로 연결되어야 한다.

#### 포함 화면
- SCR-01 대시보드 - Empty State
- SCR-02 대시보드 - 기본
- SCR-03 과제 선택 뷰

#### 공통 구조
- 상단 바: 홈 제목, 알림/프로필 액션
- 좌측 메뉴: 데스크톱에서 홈, 집중, 프로필 중심
- 메인 영역: 히어로 카드 + 할 일 목록 + 통계 영역
- 하단 메뉴: 모바일에서 홈, 집중, 프로필

#### 공통 섹션
- 히어로 영역: 현재 핵심 과제, 최근 집중 정보, `집중 시작` CTA
- 리스트 영역: 오늘의 할 일 목록, 선택/수정/삭제 가능 여부
- 통계 영역: 오늘 집중 시간, 완료 세션 수, 누적 SP, 오늘의 나무, 현재 레벨
- 보조 액션: 과제 추가, 필터, 정렬

#### 공통 상태
- 할 일 없음: SCR-01
- 일반 목록: SCR-02
- 핵심 과제 선택됨: SCR-03
- 진행 중 과제 잠금: 수정/삭제 제한

---

### 4.2 집중 모드 그룹
집중 모드 그룹은 한 과제를 수행하는 동안 사용자의 시선을 타이머와 세션 제어에만 집중시키는 공간이다. 이 그룹은 세션 상태 변화가 명확해야 하며, 대시보드보다 더 적은 정보만 보여준다.

#### 포함 화면
- SCR-04 집중 모드 - 타이머 진행
- SCR-05 집중 모드 - 일시정지/초과
- SCR-06 집중 모드 - 포기 경고 모달
- SCR-07 집중 모드 - 휴식
- SCR-08 완료 및 보상 화면

#### 공통 구조
- 메인 영역: 현재 과제명, 타이머, 세션 컨트롤
- 데스크톱 보조 영역: 다음 작업 후보, 오늘의 집중 현황 요약
- 모바일 하단 바: 포기, Pause, 필요 시 보조 액션

#### 공통 섹션
- 타이머 영역: 집중 또는 휴식 카운트다운
- 상태 배지: 진행 중, 일시정지, 휴식, 완료
- 세션 컨트롤: 포기, Pause, Resume, Skip
- 결과/보상 영역: 나무 1그루, 100 SP, 최신 통계 반영

#### 공통 상태
- RUNNING: SCR-04
- PAUSED: SCR-05
- GIVE UP CONFIRM: SCR-06
- BREAK_RUNNING: SCR-07
- COMPLETED/REWARD: SCR-08

---

### 4.3 인증/설정 그룹
인증/설정 그룹은 계정 연결, 로컬 모드 진입, 사용자 설정 관리에 집중한다. 집중 루프의 핵심 화면은 아니지만, 계정 보존과 환경 설정을 위해 V1에서 필수다.

#### 포함 화면
- SCR-09 회원가입 및 로그인
- SCR-10 프로필 및 환경설정

#### 공통 구조
- 인증 화면: 폼 카드 중심
- 설정 화면: 모달 또는 바텀시트 중심
- 프로필 요약 + 설정 리스트 + 주요 액션 버튼 구조 사용

#### 공통 섹션
- 인증 폼: 이메일, 비밀번호, 로그인/회원가입
- 로컬 모드 안내: 로그인 없이 시작, 로컬 준비 상태
- 프로필 요약: 이메일, 레벨, 누적 SP, 연결 상태
- 설정 항목: 테마, 타임존, 자동 동기화, 알림, 수동 동기화
- 계정 액션: 로그아웃

## 5. 화면별 설계 요약

### 5.1 SCR-01 대시보드 - Empty State
- 목적: 첫 과제 생성 유도
- 핵심 섹션: Empty 안내 카드, 첫 과제 추가 CTA, 비활성 집중 시작 버튼
- 보조 레이어: `SCR-02-A 과제 생성 입력 레이어`
- 핵심 메시지: 할 일을 먼저 만들어야 집중 루프가 시작된다.
- 다음 이동: `SCR-02-A` 저장 성공 후 SCR-02

### 5.2 SCR-02 대시보드 - 기본
- 목적: 오늘 할 일과 핵심 과제, 오늘의 통계를 동시에 확인
- 핵심 섹션: 히어로 카드, 할 일 목록, 통계 카드
- 보조 레이어: `SCR-02-A` 생성, `SCR-02-B` 수정, `SCR-02-C` 삭제 확인
- 핵심 액션: 과제 추가, 과제 선택, 수정, 삭제
- 다음 이동: 과제 선택 시 SCR-03, 과제 추가/수정/삭제 시 대응 보조 레이어 진입

### 5.3 SCR-03 과제 선택 뷰
- 목적: 핵심 과제 선택 상태 명확화
- 핵심 섹션: 선택된 히어로, selected row, 활성화된 `집중 시작`
- 핵심 액션: 집중 시작
- 다음 이동: SCR-04

### 5.4 SCR-04 집중 모드 - 타이머 진행
- 목적: 25분 집중 수행
- 핵심 섹션: 타이머, 현재 과제, 포기/일시정지 컨트롤, 다음 작업 후보
- 핵심 액션: Pause, Give Up
- 다음 이동: Pause 시 SCR-05, 포기 시 SCR-06, 완료 시 SCR-08 및 SCR-07

### 5.5 SCR-05 집중 모드 - 일시정지/초과
- 목적: Pause 상태 제어
- 핵심 섹션: 멈춘 타이머, 자동 취소 경고, Resume/포기 버튼
- 핵심 액션: 다시 시작, 포기
- 다음 이동: 재개 시 SCR-04, 포기 시 SCR-06, 시간 초과 시 대시보드 복귀

### 5.6 SCR-06 집중 모드 - 포기 경고 모달
- 목적: 포기 전 재확인
- 핵심 섹션: 경고 문구, 손실 안내, 계속 집중/포기 버튼
- 핵심 액션: 포기 확정 또는 취소
- 다음 이동: 확정 시 대시보드 복귀

### 5.7 SCR-07 집중 모드 - 휴식
- 목적: 5분 휴식 제공 및 Skip 선택
- 핵심 섹션: 휴식 타이머, 건너뛰기, 휴식 유지
- 핵심 액션: Skip, 휴식 유지
- 다음 이동: 자연 종료 또는 Skip 후 다음 세션/대시보드 흐름

### 5.8 SCR-08 완료 및 보상 화면
- 목적: 나무 1그루와 100 SP 지급 안내
- 핵심 섹션: 축하 메시지, 보상 요약, 확인 CTA, 저장 중 상태
- 핵심 액션: 확인, 대시보드 복귀
- 핵심 정책: 보상은 25분 집중 세션 완료 시점에 확정

### 5.9 SCR-09 회원가입 및 로그인
- 목적: 인증 및 로컬 모드 진입
- 핵심 섹션: 로그인 폼, 회원가입 폼(`displayName` 포함), 로그인 없이 시작하기, 로컬 준비 상태
- 보조 레이어: `SCR-09-A bootstrap 동기화 로딩/충돌 레이어`
- 핵심 액션: 로그인, 회원가입, 로컬 모드 시작
- 다음 이동: 로그인 성공 시 `SCR-09-A`를 거쳐 대시보드, 로컬 모드 시 비로그인 대시보드

### 5.10 SCR-10 프로필 및 환경설정
- 목적: 사용자 상태 확인 및 핵심 설정 변경
- 핵심 섹션: 프로필 요약, 테마 설정, 타임존 설정, 동기화 설정, 로그아웃
- 핵심 액션: 테마 변경, 타임존 변경, 자동/수동 동기화, 로그아웃
- 핵심 정책: 타임존은 날짜 집계 기준에 영향, 테마는 즉시 반영

## 6. 공통 네비게이션 정의

### 6.1 상단 바
- 홈 계열 화면: 화면 제목 + 알림/프로필
- 집중 화면: 제목 최소화, 필요 시 상태 배지 위주
- 인증/설정 화면: 제목 + 닫기 또는 뒤로가기

### 6.2 좌측 메뉴
- V1 기본 범위: 홈, 집중, 프로필(설정 포함)
- 대시보드 보조 탐색 용도
- V2 범위인 상점/소셜/나만의 숲은 포함하지 않음

### 6.3 하단 메뉴
- 모바일 전용
- 홈, 집중, 프로필 중심
- 집중 모드 진입 시 일반 하단 메뉴는 세션 컨트롤 바로 대체 가능

## 7. 상태 및 인터랙션 기준

### 7.1 Empty
- 대시보드에서만 명확히 정의
- 다음 행동 CTA 1개를 가장 강하게 노출

### 7.2 Loading
- 인증 제출, 동기화, 보상 저장, 초기 목록 로드에 적용
- 버튼 비활성 + 스피너 조합 사용 가능

### 7.3 Disabled
- 과제 미선택 상태의 `집중 시작`
- 진행 중 과제의 수정/삭제
- 저장 중 버튼

### 7.4 Error
- 인증 실패
- 동기화 충돌
- 네트워크 실패
- 세션 정책 위반(Pause 제한 초과 등)

### 7.5 Success
- 보상 지급
- 저장 완료
- 동기화 완료

## 8. PRD / 아키텍처 정합성 메모

### 8.1 PRD 정합성
- V1은 상점/소셜/나만의 숲을 포함하지 않는다.
- 보상은 25분 집중 세션 완료 기준으로 지급된다.
- 로컬 모드에서도 핵심 집중 루프는 동일하게 동작해야 한다.
- 테마 선택과 타임존 설정은 V1 범위에 포함한다.

### 8.2 아키텍처 정합성
- 대시보드는 Task + Reward Snapshot + DailyFocusStat 조합으로 그린다.
- 집중 타이머는 로컬 계산, 보상/SP 정산은 서버 기준이다.
- 설정 화면은 테마, 타임존, 동기화 설정과 연결되어야 한다.
- 집중 모드의 데스크톱 보조 영역은 read only로 유지한다.
